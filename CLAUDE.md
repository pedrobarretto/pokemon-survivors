# Pokémon Survivors – agent guide

Browser survivors-like (Vampire Survivors–style) with Pokémon. Vite + TypeScript + Canvas 2D, no engine. Read `README.md` for the architecture map.

## Conventions

- **Functional TypeScript only.** Use plain data (types/records) and functions. No classes or `this`. Never use `any`. Prefer inferred types and `as const satisfies` data tables, and keep content data-driven (`src/data/*`, `MOVES` in `src/game/moves.ts`).
- The simulation mutates plain state for performance (hundreds of entities at 60 Hz), and that's fine. Keep hot loops allocation-light (see `retain`, the spatial grid).
- **The simulation is deterministic**: the server re-simulates ranked runs from their replay (`src/game/replay.ts`) and must land on the same bits. In `src/game` (and anything it computes from `src/data`) use the seeded rng, never `Math.random` or the clock; use `engine/dmath` (`dm.sin`, `dm.cos`, `dm.atan2`, `dm.hypot`, `dm.exp`, `dm.pow`, `dm.sq`) instead of `Math.sin/cos/atan2/hypot/exp`, `**` or `Math.pow`, which differ between JS engines; size hitboxes from `bodyOf` (data), never from loaded sprites. Anything new the shell does to a running game (a pick, a button) goes through `recordEvent` and gets a case in `resimulate`.
- **Moves:** `MOVES` (`src/game/moves.ts`) spreads in tables that live in their own modules (`signatureMoves.ts`, `eggMoves2.ts`, `tmMoves.ts`, `verbEvolutions.ts`, `duoMoves.ts`, `legendaryMoves.ts`); a new batch gets its own module, built on the move kit (`moveKit.ts`, `moveHooks.ts`). Every base move has forks at Lv 4 and Lv 7 (`{ fork: [A, B] }` in `upgrades`), each branch with a behavior mod (`mods.ts`). Signature, legendary, duo and TM moves never evolve (`neverEvolves` in `src/data/evolutions.ts`); every other base move has an evolution. Learnsets are per evolution stage (`src/game/learnsets.ts`, `PlayableDef.learnset`, plus a branch's own moves).
- **Simulation ≠ presentation.** `src/game/*` must not touch the DOM or audio. Notify the shell by pushing a `GameEvent`; `main.ts` handles sounds, cries and toasts.
- **Pixel-perfect rendering.** The world is drawn at low internal resolution and integer-upscaled. Snap draw positions to whole pixels and use the hard-edged helpers in `engine/pixelart.ts`. New effect art is code-authored pixel strings (`render/art.ts`).
- **Three languages: pt-BR, English and Spanish (Latin America).** Every player-facing string lives in `src/i18n` (`pt.ts` is the reference; `en.ts` and `es.ts` must match it key for key, and the type checker enforces it, down to one line per move upgrade). Read text with `t()` at render time, never at module load. Pokémon, move and item names stay in English (official names) and live in the data files.
- **Comments:** short doc comments above non-obvious functions. Don't comment every line, and keep comments in sync with the code.
- **Tests:** focused vitest tests for pure rules only (`*.test.ts`). No smoke or snapshot slop.
- **SEO/GEO copy** lives in static HTML so crawlers and AI chats can read it without JS: `index.html` (pt-BR, `/`), `en/index.html` (English, `/en/`), `es/index.html` (Spanish, `/es/`) and `public/llms.txt`. When a feature changes what the game is (starters, bosses, counts), update all four.
- **Site pages** (`/pokedex/`, `/guia/`, `/novidades/`, `/legal/` and their `/en/` and `/es/` twins) are rendered at build time from `src/site` (wired in `vite.config.ts`) and read `src/data/*`, so the Pokédex and the guide's tables follow the data on their own. Their copy lives in `src/i18n/site` (`pt.ts` is the reference). Routes live in `src/site/routes.ts`, which also generates `sitemap.xml`. When a player-facing change ships, add it to `src/site/changelog.ts`: a change in today's update (revisit its 3 to 5 highlights, which the lobby's Novidades shows) or a new update on top, one per day, no PR links (players read it). `src/site/client.ts` must never import game code, so the game and the site never load each other's bundles.
- **Mobile matters:** many players will be on phones. Every UI must work with touch and on small portrait and landscape screens.

## Commands

```bash
npm run dev        # vite dev server
npm test           # vitest
npm run build      # tsc --noEmit + vite build (must pass before any PR)
npm run roster     # rebuild the wild horde (curated list in scripts/roster.mjs) from PokeAPI + SpriteCollab
npm run assets     # fetch sprites (add new dex numbers in scripts/dex.mjs; the horde comes from the roster)
npm run credits    # regenerate CREDITS.md (SpriteCollab artists) after adding species
npm run bodies     # re-measure sprite bodies (hitboxes) into sprites.generated.json; `npm run assets` does it too
node --env-file=.env.local scripts/discord/setup.mjs   # (re)build the community Discord: roles, channels, Onboarding, AutoMod (idempotent; DISCORD_BOT_TOKEN, DISCORD_GUILD_ID)
npm run typecheck --prefix server   # the accounts API (server/), typechecked with the shared game code
```

- **Accounts are optional.** Guest play (the local save) is the default and must never wait on the network. `src/account.ts` loads Clerk on demand and syncs the save to the API in `server/` (Hono + Postgres, deployed on Dokploy, see `server/README.md`). The merge rules (`mergeSaves`, `applyPush` in `src/game/sync.ts`) are shared by both sides: when a save field is added, give it a merge rule there. Without `VITE_CLERK_PUBLISHABLE_KEY` and `VITE_API_URL` the account button doesn't show.

- **Analytics and errors** go through `src/analytics.ts`: typed events (`AnalyticsEvents`) to PostHog (US cloud, behind the `/ingest` rewrite in `vercel.json`) and Umami, only on production domains. PostHog's free tier is 1M events a month and the game plays thousands of runs a day, so summarize on `run_end` instead of adding per-pick or per-frame events. Uncaught errors are reported with the running game's replay; `ps.replay(json)` plays one again. Source maps upload at build (`scripts/sourcemaps.mjs`) where `POSTHOG_CLI_API_KEY` and `POSTHOG_CLI_PROJECT_ID` are set. To try it locally, set `VITE_POSTHOG_KEY` and run `localStorage.setItem('ps:analytics', 'on')`.

In dev builds, the browser console exposes `ps.run()` (current run state), `ps.startRun('squirtle')`, `ps.theme()` (music theme playing), `ps.biome('cave')` and `ps.weather('rain')` (both hold until the next scheduled change), `ps.terrain('cliff')` (walks you to the nearest `rock`, `tree`, `cliff`, `tower` or `lake`, standing 70 px south of it; a second argument sets that distance), `ps.spawn('chansey', 3)` (enemies in an arc ahead of you; a third `true` makes them shiny), `ps.dex()` (the saved Pokédex), `ps.meadow()` (the lobby's meadow: its `wanderers`, the walking `partner` and the camera, to stage greetings), `ps.pc()` (the Caixa do PC), `ps.card(partner?)` (the Trainer Card's share preview), `ps.unlockShiny(id?)` (unlocks a shiny starter, all without an argument) and `ps.event(kind, dx?, dy?)`, which places a map event (`altar`, `fountain`, `chest`, `spikes`, `bomb`, `meowth`, `tutor`) `dx`, `dy` px from the player (default 70 px to the right) and returns it, so you can tweak its `state`. For field missions: `ps.field('defense')` (or `collect`, `escort`) starts one 120 px to the right of the player (a second argument sets the distance); the missions' director lives in `g.mapEvents.missions`. Handy for staging screenshots: set `ps.run().game.hitstop = 9999` to freeze the simulation while it keeps rendering. For Poké Balls: `ps.ball(3)` drops three 20 px to the right, inside the magnet (one with a new move or item for the build asks Take / Leave). For TMs: `ps.tm('iceBeam')` drops a TM disc 40 px to the right (`ps.tm('sacredFire', 'legendary')` a gold one) and `ps.lesson()` opens a Move Tutor's lesson at once. For bosses: `ps.trio('beasts')` swaps the run's legendary trio (`birds`, `beasts`, `regis`) for the slots still to come, and `ps.boss('entei')` brings a boss in now with its wave entrance (an earlier wave's boss flees, as it would) and `ps.bossHp(0.35)` drops it to that share of its HP, unlocking its enrage and phases (set `ps.run().game.difficulty = 'nightmare'` before `ps.boss` to see a level's patterns). For rifts and the endless mode: `ps.rift('kyogre')` steps into an arena (random legendary without an argument), `ps.portal()` opens a portal next to the player, `ps.victory()` shows the victory screen with the endless offer, `ps.endless(19.5)` jumps into endless mode at that minute and `ps.reaper()` calls Arceus now. For Mega Evolution (start a run with a line that has one, `MEGA_LINES` in `src/data/megas.ts`, e.g. `charmander`, `pichu`, `gible`): `ps.mega()` jumps to the final stage with the line's first Mega Stone and presses the Mega button (the transformation plays), `ps.mega('now', 'charizardY')` picks the Mega, `ps.mega('ready')` stops before the press and `ps.mega('stone')` drops the line's stones 40 px to the right, as a rift would (two side by side for Charizard, Raichu, Garchomp and Lucario). For eggs: `ps.egg('rare')` puts one in the incubator, `ps.walk(500)` walks the incubating eggs (all the way without an argument), `ps.hatch()` hatches every ready egg, `ps.hatch('gible', true, 2.8)` plays the hatching scene for a family (shiny, held at 2.8 s for screenshots), `ps.unlockFamily(id?)` unlocks one family or all and `ps.incubator()` opens the incubator. For missions and achievements: `ps.missions()` prints the current ones, `ps.mission(i, n?)` sets mission `i`'s progress (dailies 0-2, weeklies 3-4; default one short of done, so the next run completes it), `ps.completeMission(i)` completes and pays it, `ps.date('2026-10-19')` moves the missions' clock to that local day (`ps.date()` goes back to now), `ps.unlockAchievement(id?)` unlocks one achievement or all, and `ps.resetProgress()` wipes missions, achievements and the title. For the Surto do dia and the Poké Mart: `ps.outbreak('gastly')` holds that outbreak instead of the day's until the page reloads (no argument goes back; it plays from the next run and the title shows it), `ps.item('lure', 3)` puts items in the Bag, `ps.money(20000)` adds ₽ and `ps.unlockStyles()` owns every frame, background and wallpaper. For invites and Mystery Gifts: `ps.invite('ash', 'Ash')` lands as a guest invited by @ash (the title shows the invite banner without asking the API; needs `VITE_CLERK_PUBLISHABLE_KEY` and `VITE_API_URL`, any values do) and `ps.gift(kind, arg?, why?)` puts a gift in the lobby's gift box (Presente!, `G`) as if a sync listed it: `ps.gift('egg', 'friend', 'ash')` (`why`: the inviter's handle, or a number of friends brought), `ps.gift('coins', '500')`, `ps.gift('title')` (Ambassador), `ps.gift('style', 'ambassador', 3)` (a frame) and `ps.gift('shinyHatch', 'munchlax')` (opening it plays the hatching scene); `ps.discordGift()` puts in the thank-you for joining the Discord (`DISCORD_GIFT`). For the level-up's forks, lucky cards and Esquecer: `ps.fork('swift')` opens a level-up whose first card takes the move onto its Lv 4 fork (`ps.fork('thunder', 7)` for the second), `ps.path('swift', 8, 'AB')` sets a move's level and the branch taken at each fork it reached, `ps.offers()` opens a level-up with a rare, a shiny and a common card (`ps.offers('rare')`, `ps.offers('shiny')`) and `ps.banishes(3)` sets the Esquecer charges. For the Desafio do dia: `ps.challenge()` opens its screen and returns today's challenge, `ps.challenge('play')` starts it, `ps.challenge('done', 754)` marks this device's official attempt as made (the screen then says practice) and `ps.challenge('reset')` forgets it; `ps.gift('ribbon', 'gold')` puts yesterday's ribbon in the gift box. For supporters: `ps.supporter()` puts the Supporter tier's gifts in the gift box (title, frame and a shiny ticket, which offers the shiny picker as it opens; the Hall card sparkles while a ticket waits for its pick) and `ps.supporter('gold')` every tier at once, gold background and wallpaper included (one sync, like a first donation of R$ 50), `ps.gift('shinyPick')` adds one more ticket, and `ps.companion('pichu', true)` takes a companion along from the next run (no argument walks alone; it needs the Supporter title and the Pokémon unlocked). For moves: `ps.learn('roarOfTime', 5)` gives the running game any move at a level, past the learnset and the slot cap, and `ps.path('sacredFire', 5, 'B')` takes a fork's branch; `ps.sig('dig')` swaps the run's moves for that signature at its max level (`ps.sig('dig', 3, true)` adds it at Lv 3 beside the others; `ps.sig()` lists the egg signatures) and `ps.kit('sweep')` casts a move-kit primitive with stand-in moves (`status`, `sweep`, `return`, `pull`, `strike`, `trailer`, `wander`, `guard`, `burrow`, `throw`, `execute`, `drain`; `ps.kit('status', 'freeze')` puts one condition on the foes in view). For evolutions: `ps.evolve()` levels up to the next evolution, asking where a branching one goes (`ps.evolve('vaporeon')` takes that branch), and `ps.ability()` opens the Ability pick now (`ps.ability('blaze')` takes that one). For duos and curses: `ps.duo('firePledge')` maxes a move of each of the recipe's types and opens a level-up with the golden duo card (`ps.duo('ionDeluge', 'now')` fuses on the spot), and `ps.curse('lifeOrb')` opens a chest's cursed item choice (`ps.curse('ironBall', 'take')` just takes it). For the world's hazards: `ps.hazard('volley')` fires one attack at the player now (`line`, `zone`) and `ps.hazard('auto', 10)` jumps the run to minute 10 with the next attack due. The legendary moves (one per rift legendary and mythical, `LEGENDARY_MOVE_OF` in `src/data/legendaryMoves.ts`) are `whirlwind`, `sacredFire`, `originPulse`, `scorchingSands`, `dragonAscent`, `roarOfTime`, `mistBall`, `lusterPurge`, `psychoBoost`, `ancientPower`, `magicalLeaf` and `wish`; stage one with `ps.learn(id, 5)` and `ps.spawn('rattata', 30)`. For content creators (`CREATORS` in `src/data/creators.ts`): `ps.live('birdseyegames')` stages that creator as live for the lobby's Criadores card (`ps.live()` every creator, `ps.live(false)` asks the API again); on the site, `/criadores/?live=birdseyegames` (or `?live=all`) does the same in dev. For spitters: `ps.spitter('charmander', 5)` puts 5 spitters in an arc 150 px ahead of the player (the stage's own spitter species without a name). For Alphas: `ps.alpha('golem')` brings an Alpha 120 px ahead of the player (the stage's own pick without an argument). For the pressure director: `ps.tension()` prints it (level 0..1, reach, harm and what it does to the spawns now) and `ps.tension(0.8)` sets its level, marking the player dominant so it holds until they get hurt (before 10:00 the run's ceiling, `tensionCeiling`, pulls it down).

## Assets

Pokémon sprites come from PMD SpriteCollab (`sprite/<dex>/` has Walk/Idle/Hurt; shiny forms live under `sprite/<dex>/0000/0001/`). Portraits also come from SpriteCollab and cries from PokeAPI. They are downloaded by `scripts/fetch-assets.mjs` into `public/assets/pokemon/<dex>/` and indexed in `src/data/sprites.generated.json`. SpriteCollab is CC BY-NC 4.0 with per-artist credit, so keep `CREDITS.md` in sync (`npm run credits`).
